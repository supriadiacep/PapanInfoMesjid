Kebijakan Privasi Papan Info Masjid

Berlaku sejak 29 Oktober 2026

Papan Info Masjid adalah aplikasi untuk menampilkan jadwal sholat, hitung mundur iqomah, pengumuman, jadwal pengajian, dan laporan kas masjid di layar TV. Halaman ini menjelaskan data apa saja yang dipakai aplikasi dan bagaimana data itu diperlakukan.

Ringkasan

Aplikasi ini tidak mengumpulkan, mengirim, atau membagikan data pribadi apa pun kepada pengembang maupun pihak lain. Aplikasi tidak memakai iklan, analitik, pelacakan, atau layanan pihak ketiga. Semua isi papan info hanya tersimpan di perangkat tempat aplikasi dipasang.

Data yang disimpan di perangkat

Data berikut dimasukkan sendiri oleh pengurus masjid dan disimpan di penyimpanan internal aplikasi pada perangkat (TV box atau tablet). Data tidak pernah dikirim ke server pengembang.

  • Isi papan info: nama dan alamat masjid, koordinat masjid (untuk menghitung waktu sholat), jadwal pengajian, nama petugas Jumat, pengumuman, teks berjalan, dan laporan kas.
  • Foto masjid yang dipilih pengurus (opsional).
  • PIN pengurus untuk melindungi halaman pengaturan.

Koordinat masjid diketik secara manual. Aplikasi tidak meminta izin lokasi dan tidak membaca lokasi perangkat.

Pengaturan dari HP di jaringan lokal

Agar isi papan info bisa diubah dari HP, aplikasi menjalankan server kecil yang hanya bisa diakses dari jaringan WiFi yang sama (misalnya 192.168.1.25:8080). Server ini dilindungi PIN dan tidak terhubung ke internet. Data yang dikirim dari HP langsung disimpan di perangkat TV, tidak melewati server pengembang.

Izin yang dipakai

IzinKegunaan
InternetMenjalankan server pengaturan di jaringan lokal (WiFi masjid).
Status jaringan & WiFiMenampilkan alamat yang perlu dibuka di HP untuk mengatur papan info.

Mencegah layar matiMenjaga layar tetap menyala selama papan info tampil.

Menghapus data

Semua data bisa dihapus kapan saja dengan menghapus data aplikasi (Setelan → Aplikasi → Papan Info Masjid → Penyimpanan → Hapus data) atau dengan meng-uninstall aplikasi. Karena pengembang tidak menyimpan salinan data apa pun, tidak ada data yang perlu diminta untuk dihapus dari pihak pengembang.

Anak-anak

Aplikasi ini ditujukan untuk pengurus masjid dan tidak ditujukan untuk anak-anak. Aplikasi tidak mengumpulkan data dari siapa pun, termasuk anak-anak.

Perubahan kebijakan

Bila kebijakan ini berubah, versi terbaru akan dipasang di halaman ini dengan tanggal berlaku yang baru.
